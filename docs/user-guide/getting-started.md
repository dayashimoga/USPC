# USPC User Guide: Files, Photos, Video & Audio

USPC delivers a unified **Files + Media Library** interface designed for fast, seamless access to your personal files, 4K videos, high-resolution photos, and music libraries.

## 1. Web Interface Overview

Access the modern single-page dashboard at `http://127.0.0.1:8085` (or your private VPN mesh IP):

- **1-Click Video Streaming**: Click on any video thumbnail to launch the integrated HTML5 player immediately with instant seeking without downloading the full file.
- **1-Click Audio Dock**: Click on any music track to start playback in the bottom dock player with playlist queue and background listening.
- **1-Click Photo Lightbox**: Click on any image for high-resolution inspection with EXIF metadata.
- **1-Click Upload & Drag-and-Drop**: Drag any file onto the browser window or click the **Upload** button.

---

## 2. Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Space` | Toggle Video Play / Pause |
| `Arrow Right` | Seek Forward (+5 seconds) |
| `Arrow Left` | Seek Backward (-5 seconds) |
| `F` | Toggle Video Fullscreen |
| `M` | Mute / Unmute Audio |
| `Esc` | Close Video Player or Photo Lightbox |

---

## 3. Desktop & Mobile Sync Clients

USPC is 100% compatible with official Nextcloud clients:

1. **iOS / Android**: Download the Nextcloud app and enter your server URL (`http://100.64.0.1:8081`).
2. **Windows / macOS / Linux**: Install the Nextcloud Desktop Sync client to mirror files and folders.
